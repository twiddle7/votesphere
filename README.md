# VoteSphere — Real-Time Polling & Voting System

An academic AWS cloud-computing project: create polls, vote, and see live results
via WebSockets. Built with **S3 + API Gateway (HTTP + WebSocket) + Lambda (Python 3.12)
+ DynamoDB + CloudWatch + IAM**.

## Features
- Create polls with 2–10 options and optional closing time
- Explore, search, filter polls
- Vote with duplicate-vote protection (per browser voter ID)
- Real-time result updates via WebSocket API
- Charts (Chart.js) + progress bars + status badges
- CloudWatch logs and least-privilege IAM
