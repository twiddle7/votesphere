Cloud Architecture

Purpose

VoteSphere is an academic cloud-computing project demonstrating a real-time, serverless polling system built entirely on AWS managed services. Users create polls, cast votes, and watch results update in real time via WebSockets.

AWS Services Used

  • Amazon S3 — hosts the static frontend (HTML / CSS / JS).
  • API Gateway HTTP API — REST endpoints for polls and votes.
  • AWS Lambda (Python 3.12) — backend business logic.
  • Amazon DynamoDB — stores polls, votes, and WebSocket connections.
  • API Gateway WebSocket API — pushes live vote updates to subscribers.
  • Amazon CloudWatch — logs and monitoring for Lambda functions.
  • AWS IAM — least-privilege roles for each Lambda function.

Real-Time Flow

  1. User opens the Live Results page and the browser opens a WebSocket connection.
  2. The client sends { action: 'subscribe', poll_id } to the WebSocket Lambda.
  3. The Lambda stores the connection ID and poll ID in DynamoDB.
  4. When any user votes, the REST Lambda updates DynamoDB and calls the API Gateway Management API.
  5. All subscribed browsers instantly receive the updated results over WebSocket.
  6. Charts and progress bars re-render without a page reload.
